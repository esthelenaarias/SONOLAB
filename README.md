# SONOLAB
SONOLAB es un anteproyecto escolar de grado 8.º del Colegio Jorge Gaitán Cortés (Bogotá). Desarrolla un sistema IoT con el microcontrolador ESP32 y sensores para medir el ruido escolar en tiempo real, emitir alertas visuales/sonoras por LED/buzzer y generar recomendaciones según normas ambientales y de la OMS.
